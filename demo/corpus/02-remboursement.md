# Politique de remboursement

Notre politique de remboursement accorde un delai de 30 jours apres l'achat.
Pour demander un remboursement, contactez le support depuis votre espace client.

Le remboursement est effectue sur le moyen de paiement d'origine.
Le delai de traitement est de cinq jours ouvres apres validation.

Sont exclus du remboursement les services deja consommes integralement.
En cas de litige, le support reexamine la demande avec l'historique de commande.
